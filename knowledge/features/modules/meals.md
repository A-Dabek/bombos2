# Meals Feature Module

The Meals feature provides dinner and supper meal planning, meal catalog administration, and a random meal picker widget.

## Core Capabilities & Workflows

1. **Meal Planning**: Select and track meals for days and meal times (dinner, supper).
2. **Meal Administration**: Manage the master list of available meals.
3. **Randomizer**: Randomly select a meal suggestion from the catalog.
