# Allowance Feature Module

The Allowance feature tracks allowance configuration, periodic allocation calculations, and transaction history.

## Core Capabilities & Workflows

1. **Allowance Configuration**: Configure base allowance amounts and period calculation rules.
2. **Transaction Tracking**: Record and view allowance transactions grouped by period.
